# Dotastat

📊 A web application for displaying and analyzing Dota 2 statistics.

## 🚀 Features
- Store match and player data in a MySQL database.  
- Visualize statistics through a web interface.  
- Simple architecture: PHP + MySQL + CSS + JS.  

## 🛠️ Technologies
- **Backend**: PHP  
- **Frontend**: HTML, CSS, JavaScript  
- **Database**: MySQL (`dota_stat.sql`)  

## 📂 Project Structure
- `/scripts` — PHP scripts for database operations and app logic.  
- `/Style` — CSS styles for UI.  
- `dota_stat.sql` — database dump for setting up the project.
